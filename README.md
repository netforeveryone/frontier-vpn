# KRPray — downloads

Official installers and APKs for **KRPray** (Android + Linux + Windows + macOS). Source code is maintained in private repositories; this repository only hosts release assets and checksums.

## Latest release

See **[GitHub Releases](https://github.com/netforeveryone/krpray/releases)** for the current `v*` tag.

| Platform | Files |
|----------|--------|
| Android | Four per-ABI `KRPray_*_*.apk` plus `*.aab` |
| Linux | `.deb`, `.AppImage`, `KRPray_*_linux_amd64_portable.zip` |
| Windows | NSIS `KRPray_*_x64-setup.exe` (or similar), `KRPray_*_windows_x64_portable.zip` |
| macOS | `KRPray_*_macos_universal.dmg` |

Verify downloads with `SHA256SUMS` in this repository (updated when a release is published).

## Config feeds

Subscription lists are produced by the separate [netforeveryone/vpn](https://github.com/netforeveryone/vpn) pipeline (not hosted here).
